# Contributing Corrections and Evidence

This register accepts documented corrections, stronger source routes, clarified dates, duplicate-identity evidence, and rights or attribution concerns.

Use the repository's **Record correction** issue form and provide:

1. The affected Claim ID, Master ID, Canonical Object ID, Price Observation ID, Source ID, or Chronology ID.
2. The current statement or value.
3. The proposed correction.
4. A public source URL or a clear description of privately held evidence.
5. Any rights or access limitation that affects public verification.

Do not upload protected historical scans unless you own the rights or have explicit permission to share them. A citation, page reference, or description is usually sufficient for review.
