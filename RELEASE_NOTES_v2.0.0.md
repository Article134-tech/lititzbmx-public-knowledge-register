# Lititz BMX Public Knowledge Register v2.0.0

## Release scope

- Expanded from 500 to 1,010 permanent Source Records.
- Added the approved search-first Lititz BMX homepage experience.
- Added the global Archive, YouTube, Spotify, Facebook, GitHub, and Donate destination header.
- Added curated entry points for Harry Leary; GT, Dyno, Auburn, and Robinson; Diamond Back; catalogs; advertisements; historical prices; BMX Action Bike; and Bicross.
- Added direct record-specific source-page routing for 880 PreviousPage-backed records.
- Added explicit exact-page-unresolved treatment for 87 PreviousPage-backed records.
- Preserved 1,000 provisional Canonical Objects, 717 Price Observations, 73 registered sources, 69 Public Claims, and 3,879 search entries.

## Rights boundary

The release indexes and describes historical source material without redistributing protected magazine scans. Source links, paraphrased facts, limitations, and correction routes remain visible.

## Deployment state

The exact candidate was approved by Kyle A. Huffman on August 2, 2026 and is cleared for controlled deployment. The public site remains unchanged until the authorized package is committed and pushed. Final QA, release authorization, live-verification requirements, and rollback instructions are included with the release.
