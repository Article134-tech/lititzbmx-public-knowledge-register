CAT-HARO-1990

1990 Haro BMX Catalog

Official catalog existence verified; exact external reference ID remains unresolved.

Haro's official BMX archive verifies a manufacturer-issued 1990 catalog. An independent catalog reconstruction organizes six model entries for the year, while a public index exposes a matching reference titled “1990 Haro BMX Catalog.” The exact external numeric reference ID, edition and page-for-page match remain unresolved.

What the Evidence Supports

VerifiedIdentity

Haro issued a BMX catalog for 1990.

Approved public wording: Haro's official archive verifies the existence of a 1990 BMX catalog.

Why this status: The first-party archive lists 1990 among its historical BMX catalog years.

Sources: Haro BMX Catalog Archive

Last reviewed 2026-07-30 · Permalink to this claim

Open questionIdentity

The exact external numeric reference ID has been recovered.

Approved public wording: A public index exposes the external reference title, but its numeric reference ID has not been recovered.

Why this status: Search indexing exposes the title and an externally hosted image filename, but no ordinary public backlink reveals a /reference/{id} URL.

What this does not prove: The image filename cannot be used to infer or invent the reference ID.

Sources: Public Index Exposing Haro Catalog Titles

Last reviewed 2026-07-30 · Permalink to this claim

Open questionContext

The reconstruction is necessarily the same edition as the external reference.

Approved public wording: The reconstruction is a useful model-year guide, but edition, market and page matching remain open.

Why this status: Official archive, reconstruction and title indexing support the same year without proving identical files or editions.

What this does not prove: Matching year and title do not establish identical pagination or market specification.

Sources: Haro BMX Catalog Archive, 1990 Haro Model-Year Reconstruction, Public Index Exposing Haro Catalog Titles

Last reviewed 2026-07-30 · Permalink to this claim
