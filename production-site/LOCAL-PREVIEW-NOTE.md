# Local Preview Note

The approved Lititz BMX logo already lives in the target repository at:

`brand-assets/logos/Lititz-BMX-Logo-Black-Tire-Black-Lettering.png`

The site references that parent-repository asset by its deployed site path:

`/brand-assets/logos/Lititz-BMX-Logo-Black-Tire-Black-Lettering.png`

When opening these HTML files directly from an extracted ZIP, that parent path does not exist. The page therefore displays a plain text `LITITZ BMX` fallback in the white logo field. After the `public-knowledge-register` folder is copied into `lititzbmx-docs` and deployed, the approved logo should replace that fallback automatically.

The package intentionally does not include a recreated, screenshot-derived or unverified logo copy.
