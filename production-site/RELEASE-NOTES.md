# Release Notes — 1.0.0-rc1

## Purpose

Replace the generic v1.8 structural prototype with the established Lititz BMX public visual system while preserving the evidence schema underneath.

## Added

- Dark Lititz BMX header and footer with approved-logo path
- Warm orange brand accent, cream archival field, blue evidence links, gold qualified boundaries and green verified states
- Responsive navigation and mobile menu
- Public-facing evidence language
- Searchable 14-record publication queue
- Exact itemization for 32 catalogs/guides, 17 advertisements/tests, 10 flyers/mailers and 16 historical price observations
- 17-entry evidence-controlled chronology
- 10-target permission-free recovery queue
- Four fully branded detailed record pages
- JSON records and schema downloads
- Sitemap, release documentation, validation report and SHA-256 manifest

## Deliberately excluded

- BMXMuseum images, descriptions, forum bodies, member profiles and classifieds
- Third-party catalog or magazine scans
- Unverified numeric reference IDs
- Unsupported rarity, ownership or factory-sequence claims
- Existing repository-root changes

## Public review status

This is a release candidate intended for owner deployment and live verification. The next commit, after verification, should add the Register link to the repository root documentation.
