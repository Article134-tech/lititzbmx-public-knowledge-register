# Deployment Instructions — GitHub Desktop

## Locked destination

`Article134-tech/lititzbmx-docs/lititzbmx-public-knowledge-register/`

Branch: `main`

## Copy step

1. Extract `Lititz_BMX_Public_Knowledge_Register_Branded_Release_Candidate_v1.0.0.zip` in Downloads or another location **outside** the cloned repository.
2. Open the extracted wrapper folder.
3. Copy the single inner folder named `public-knowledge-register`.
4. Paste that folder into the root of the local `lititzbmx-docs` repository, beside existing folders such as `brand-assets`, `campaigns`, `learning-resources`, and `record-collection`.
5. Do not copy the outer release-wrapper folder into the repository.

## GitHub Desktop

1. Open GitHub Desktop.
2. Select repository `Article134-tech/lititzbmx-docs`.
3. Confirm the current branch is `main`.
4. Review Changes and confirm that only files inside the new `public-knowledge-register/` folder are being added.
5. Commit summary: `Add branded Public Knowledge Register release candidate`
6. Commit to `main`.
7. Click **Push origin**.
8. Stop and verify before changing the repository root README.

## Expected public URL

https://article134-tech.github.io/lititzbmx-public-knowledge-register/

## Required first checks

- The approved logo displays from `/brand-assets/logos/Lititz-BMX-Logo-Black-Tire-Black-Lettering.png`.
- Navigation works on desktop and mobile.
- The four detailed record pages open.
- Browse filters work.
- Every homepage number opens an itemized list.
- No existing repository page or folder was overwritten.

After those checks, update the repository root index/README in a separate commit.
