# Product Navigation Implementation — v1.1.0

## Hierarchy

- **Overview:** release home and totals
- **Explore:** Claims, Records, Objects, Prices
- **Evidence:** Sources, Chronology, Validation
- **Resources:** Data, Downloads, Methodology
- **External:** View Archive, View on GitHub

## Implemented behaviors

- Shared desktop and mobile navigation
- Current-page treatment through `aria-current="page"`
- Accessible mobile menu with `aria-expanded` and Escape-to-close
- Breadcrumbs on every generated index and detail page
- Explicit project-root routes for GitHub Pages and mobile in-app browsers
- Clickable homepage metrics with inspect actions
- Relationship navigation among records, objects, prices, and sources
- Direct correction actions on claim, record, and source detail pages
- Search counts, Reset controls, zero-result messages, and match highlighting
- Mobile card transformation for public data tables
- No-JavaScript record visibility
