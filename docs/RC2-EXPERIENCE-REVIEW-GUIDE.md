# RC2 Experience Review Guide

This is an offline candidate. The public v1.2.0 site is unchanged.

## Five-minute review

1. Open the standalone preview HTML.
2. Search for `EPH-1010`, `Harry Leary`, `Mongoose`, `1982`, and `Bicross`.
3. Open one result and confirm the record reads naturally before technical fields appear.
4. Narrow results using the layer buttons.
5. Resize the browser window to phone width and check that the page remains calm and readable.

## Approval questions

- Is the first action obvious?
- Does the homepage feel simple rather than empty?
- Do record pages explain the object without forcing database terminology on the reader?
- Are evidence, uncertainty, and corrections easy to find without dominating the page?
- Is anything visible that does not earn its place?

No deployment should occur until these questions are answered positively.
