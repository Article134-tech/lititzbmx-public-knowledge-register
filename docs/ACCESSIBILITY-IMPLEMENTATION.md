# Accessibility Implementation — v1.1.0

## Implemented

- Semantic page landmarks and breadcrumbs
- Skip-to-main-content link
- Keyboard-visible focus indicators
- Accessible mobile-menu state and Escape handling
- Active-page announcements through `aria-current`
- Visible search labels and live result counts
- Explicit zero-result messages
- Minimum 44-pixel primary controls
- Text-bearing rectangular status labels; color is supplemental
- Responsive labeled mobile cards for tabular indexes
- Reduced-motion accommodation
- Descriptive action links
- Decorative footer logo uses empty alternative text; masthead logo has a descriptive alternative
- JavaScript enhances filtering and navigation but does not create the records

## Live-only checks after deployment

- Keyboard traversal on the deployed site
- 200% and 400% zoom
- VoiceOver or TalkBack spot checks
- Actual-phone touch and orientation checks
- Live browser console and network review
