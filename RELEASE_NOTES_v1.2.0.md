This release expands the public register to 500 Source Records and introduces category-first browsing and scale-ready record discovery.

- 500 Source Records
- 490 provisional Canonical Objects
- 335 source-specific Price Observations
- 65 Registered Sources

## Interface improvements

- Category landing pages
- Full-register search
- Category, decade, brand/promoter, geography, status, and price-evidence filters
- Sorting by ID, date, title, and category
- Progressive loading in groups of 25
- Responsive record and evidence cards
- Accessible mobile menu and keyboard behavior
- Separate actions for register records and original evidence sources

No protected historical catalog, flyer, advertisement, publication, or BMXMuseum source scan is reproduced. The release preserves metadata, public URLs, citations, descriptive facts, limitations, rights treatment, confidence, and correction pathways.
